# Usman Tariq — Personal Portfolio

A modern, responsive personal portfolio built for the Inovegen Internship Task 4 (Front-End Web Development).

## Features
- Responsive desktop, tablet, and mobile layouts
- Semantic HTML sections and accessible labels
- Mobile navigation with open/close and Escape-key support
- Scroll progress indicator and sticky header
- Active navigation section highlighting
- Scroll reveal animations (respects reduced-motion preferences)
- Back-to-top control
- Contact form with client-side validation and feedback
- Custom CSS illustrations; no image assets required

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, custom properties, media queries)
- Vanilla JavaScript

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser.
3. For a local development server, use VS Code Live Server or run `python -m http.server 8000` in this folder, then visit `http://localhost:8000`.

## Before submitting
Personalize the sample content:
- Confirm your name, degree, university, skills, and experience.
- Replace `hello@example.com` with your actual professional email.
- Replace the LinkedIn and GitHub URLs with your own profile URLs.
- Replace the sample dashboard and travel concepts with your own completed projects, screenshots, and working project links.
- Adjust skill descriptions/indicators so they accurately reflect your current ability.
- Test all breakpoints and form validation on desktop and mobile.

## Contact form note
The form currently performs browser-side validation and displays a success message. It does not send or store messages. Connect a trusted form endpoint/service if you want to receive submissions.

## Deployment
You can deploy this static site using GitHub Pages, Netlify, or Vercel. Upload all three files (`index.html`, `style.css`, and `script.js`) while keeping them in the same folder.
